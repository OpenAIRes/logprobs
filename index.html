Logprobs

Jedna databáze volání gpt-3.5-turbo-instruct a nad ní několik pohledů. Vyber, jestli chceš jeden řetězec token po tokenu, nebo seznam řetězců — a jaký.
načítám stav storu…

Jeden řetězec

Strom token po tokenu. U každého tokenu vidíš 20 alternativ s jejich logprobs a kliknutím se po některé vydáš dál. Data se berou z historie, sweepů i storu — API se volá jen na to, co nikde není.

Seznam řetězců

Žebříčky a mřížky nad všemi záznamy. Server je počítá živě, takže seznam nikdy nezůstane pozadu za daty.

Generovat dál

Builder rozbaluje vždy nejlepší dosud nevyzkoušený kandidát, takže databáze roste v tom pořadí, ve kterém se pak čte. Umí i simulaci bez API — a se zapnutým storem bere hotová volání zdarma.
