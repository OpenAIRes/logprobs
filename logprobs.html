What each control does

New tree…
Starts a new tree. The dialog asks for the starting prompt — empty means unconditional, i.e. what the model says on its own. A given prompt is shown greyed in the text; it has no alternatives, because the API returns logprobs only for tokens it generated.
Generate 4096
Throws away the continuation shown and generates a new one from the same prompt, up to the model's ceiling. Orders of magnitude dearer than ordinary clicking — one press costs about as much as two hundred token clicks.
Prompty
Every prompt in the history, searchable. Click one to see its records and switch to any of them.
Raw record
The current record as JSON: the request sent, tokens, logprobs, usage, the call id. Editable and savable.
Export
Downloads the whole history as completion_history.json. The number is how many records it holds.
Sweep cache
Imports the sweep databases as a read-only cache. A token click then looks in this browser's own history first, then here, and calls the API only when nothing has the answer. The import is one-off and permanent, and lives in a separate database, so it cannot damage your history.
Store
Asks the store (server.py) for records this browser does not have — and only after its own history and the sweep cache, i.e. as the last stop before a call is paid for. The number is how many records the store holds; — means it is not answering (a plain static server, or not running). Switching it off makes the program behave exactly as it did before, and it does the same by itself whenever the store cannot be reached.
Opravit odkazy
Recomputes, for each prompt token, the link to the record it came from. Only needed when those links are missing or wrong.
Vymazat historii
Permanently deletes the history in this browser. The sweep cache stays. Export first.
model
Which model generates. It is stored in every record, so data from different models never gets mixed. davinci-002 and babbage-002 return only 5 alternatives per position instead of 20.

V textu

klik na token
Shows the 20 most probable alternatives at that position with their logprob and probability. Clicking one in the table branches the tree — it generates the continuation as if the model had picked that token there.
the status message
Loaded = from this browser's history · Loaded from the sweep cache or from the store = no call was made · Saved = the API really was called and it cost money.
