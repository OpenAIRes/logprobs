Co která věc dělá

Nový strom…
Založí nový strom. V dialogu zadáš výchozí prompt — prázdný znamená nepodmíněný začátek, tedy co model řekne „sám od sebe“. Zadaný prompt se v textu zobrazí šedě; nemá alternativy, protože jeho logprobs API nevrací.
Dogenerovat 4096
Zahodí zobrazené pokračování a vygeneruje z téhož promptu nové, dlouhé až na strop modelu. Řádově dražší než běžné klikání — jedno stisknutí stojí asi tolik jako dvě stě kliknutí na token.
Prompty
Seznam všech promptů v historii s hledáním. Kliknutím na prompt uvidíš jeho záznamy a můžeš se na kterýkoli přepnout.
Zdrojová data
Surový JSON aktuálního záznamu: odeslaný request, tokeny, logprobs, usage, identifikátor volání. Jde i editovat a uložit.
Export
Stáhne celou historii jako completion_history.json. Číslo udává, kolik záznamů v ní je.
Sweep cache
Načte sweep databáze jako cache pro čtení. Klik na token pak hledá nejdřív ve vlastní historii, pak tady, a API volá jen když data nemáme. Import je jednorázový a trvalý; leží v oddělené databázi, takže tvou historii nemůže poškodit.
Opravit odkazy
Přepočítá u promptových tokenů odkazy na záznamy, ze kterých pocházejí. Potřeba jen když odkazy chybí nebo nesouhlasí.
Vymazat historii
Nevratně smaže historii v prohlížeči. Sweep cache zůstává. Nejdřív Export.
model
Kterým modelem se generuje. Do každého záznamu se ukládá, takže se data z různých modelů nemíchají. davinci-002 a babbage-002 vracejí jen 5 alternativ na pozici místo 20.

Nový strom — výchozí prompt

Nechej prázdné pro nepodmíněný strom (jako dosud). Jinak se strom založí z tohoto textu. Prompt se v zobrazení ukáže jako jeden celek — jeho logprobs neznáme, API je vrací jen pro vygenerované tokeny.

20 se shoduje se sweep daty, takže je větší šance na zásah cache místo placeného volání.
